## Redrafting America

Redrafting America is a nonprofit civic initiative designing **Constitution v2.0**—a
modern constitutional framework for a future democratic society built around truth,
accountability, and human dignity.

We are asking what a constitution written today, informed by everything the last two
and a half centuries have taught us, should say.

**[Visit redraftingamerica.org](https://redraftingamerica.org)**

## What we are building

- **Constitution v2.0** — the flagship constitutional framework, its institutions, and
  the supporting work that explains their design.
- **Redrafting America infrastructure** — the public website and the operational tools
  needed to support the initiative.
- **System Observatory** — a native macOS product in development that turns idle
  displays into useful, thoughtfully designed information surfaces. Its development
  repositories are currently hosted by this GitHub organization; its final ownership
  model has not yet been decided.

## System Observatory

> Always useful screensavers. Never flying toasters.

System Observatory is designed around three complementary display experiences:
**C-TOP**, **M-TOP**, and **L-TOP**. The native application and its public website have
separate repositories so each can evolve and ship independently.

**[Visit systemobservatory.app](https://systemobservatory.app)**

## Where things stand

Redrafting America is in its pre-launch formation and drafting phase. Work remains
subject to revision until it is explicitly identified as released. We use documented
versions and lifecycle states so published material can be identified and traced.
